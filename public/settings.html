            Coach and integrations

            API tokens

            For an assistant or a script acting as you. A token is for the MCP server unless you give it REST access too; either way it writes as an agent, so it can't add or accept goals, erase a finished session or change your own notes. Revoke it here when you're done with it.

              Copy it now: it won't be shown again.

              Connect an assistant

              Make a token above, then connect. The MCP server (Streamable HTTP) gives an assistant tools to read your training and plan workouts. Point the client at this address with the token in an Authorization: Bearer <token> header; a script sends the same header to the API with a token that has REST access.

              If the server is reached by a name other than a loopback address, whoever runs it lists that name in MCP_ALLOWED_HOSTS; until then the server refuses MCP requests. The MCP docs list the tools.
