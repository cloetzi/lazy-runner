              Connect an assistant

              Make a token above, then connect. The MCP server (Streamable HTTP) gives an assistant tools to read your training and plan workouts. Point the client at this address with the token in an Authorization: Bearer <token> header, the same header a script sends to the API.

              If the server is reached by a name other than a loopback address, whoever runs it lists that name in MCP_ALLOWED_HOSTS; until then the server refuses MCP requests. The MCP docs list the tools.
